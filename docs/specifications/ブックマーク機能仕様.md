# ブックマーク機能 現行仕様

[共通仕様へ戻る](アプリケーション仕様.md)

## 1. 概要

Discordのブックマーク用チャンネルに投稿されたWebページのURLから、Scrapboxにブックマークページを作成する。

`BOOKMARK_CHANNEL_ID`が設定されていない場合、この機能は動作しない。

## 2. 処理対象の投稿

`BOOKMARK_CHANNEL_ID`で指定したチャンネルへの投稿だけを処理する。Bot自身の投稿は処理しない。

投稿本文の1行目が、前後の空白を除いてHTTPまたはHTTPSのURLだけである場合に、そのURLをブックマーク対象とする。1行目がURLだけでない投稿と、URLを含まない投稿は無視する。

投稿本文の2行目以降は、空行を含めてそのままページ本文として扱う。

画像が添付されている場合は、1枚目の画像だけを使用する。

## 3. Webページ情報の取得

ブックマーク対象のURLを取得し、HTMLから以下を読み取る。

- タイトル: `og:title`、なければ`<title>`の内容
- 画像: `og:image`の内容

タイトル中の改行や連続する空白は1つの半角空白にまとめる。

URLの取得に失敗した場合や、タイトルを読み取れない場合は、URLそのものをタイトルとする。

## 4. 画像

ページに載せる画像は、以下の順で決める。

1. 投稿に添付された1枚目の画像
2. Webページの`og:image`の画像

決めた画像をGyazoへアップロードし、Gyazoのパーマリンクをページに記載する。

画像が存在しない場合や、`og:image`の画像を取得できない場合は、画像の行を記載しない。

Gyazoへのアップロード、または添付画像の読み込みに失敗した場合は、画像の行を記載せずにページ作成を続ける。

## 5. ページ内容

作成するページの内容は以下のとおりとする。

```
(タイトル)
[Gyazoのパーマリンク]
[ブックマーク対象のURL]
(投稿本文の2行目以降)
```

画像の行は、画像をアップロードできた場合だけ記載する。

ページはScrapboxのページデータimport用エンドポイントを使って`COSENSE_PROJECT`へ作成する。

## 6. 同名ページの扱い

作成前に同じタイトルのページが存在するか確認する。存在する場合はページを作成しない。

## 7. Discord通知

ブックマーク対象の投稿を受け取ったら、処理を始める前に、その投稿へ👍のリアクションを付ける。リアクションの追加に失敗した場合は標準出力へ記録し、処理を続ける。

処理結果は、元の投稿への返信として通知する。

返信は、ブルーアーカイブの天童ケイを思わせる丁寧でやや素直でない口調とする。

| 状況 | 返信内容 |
| --- | --- |
| 作成成功 | 保存した旨、作成したページのURL、読み返しを促す一言 |
| 作成成功、画像の処理に失敗 | 作成した旨、作成したページのURL、画像を外した旨、原因 |
| 同名ページが存在 | 同名ページがあるため作成しなかった旨と、既存ページのURL |
| ページ作成に失敗 | 作成できなかった旨、警告チャンネルへ報告する旨、原因 |

ページ作成に失敗した場合は、`DISCORD_ALERT_CHANNEL_ID`で指定したチャンネルへも、対象URLと原因を通知する。

返信の送信に失敗した場合は、標準出力へ記録する。
