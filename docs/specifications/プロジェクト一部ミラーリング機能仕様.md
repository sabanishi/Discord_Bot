# プロジェクト一部ミラーリング機能仕様

[共通仕様へ戻る](アプリケーション仕様.md)

## 1. 概要

Privateプロジェクトの一部をPublicプロジェクトへミラーリングする。


## 2. 複製対象ページの判定

Privateプロジェクト内のページを複製対象候補とし、除外タグまたは除外アイコンを含むページは複製しない。

除外タグおよび除外アイコンは、Privateプロジェクト内の設定ページで管理する。

初期設定は以下とする。

- `#diary`
- `#研究`
- [private.icon]

除外設定ページの本文には、除外タグをハッシュタグ記法で、除外アイコンをScrapboxのページリンク記法で記載する。

```text
ミラーリング対象外設定

#diary
#研究
#個人情報

[private.icon]
[secret.icon]
```

本文中の`#`から始まる文字列を除外タグとして扱い、`.icon`で終わるページリンクを除外アイコンとして扱う。1行に複数の設定を記載でき、説明文と空行は無視する。

設定ページに記載した除外タグおよび除外アイコンは、初期設定へ追加する。

## 3. 複製内容

複製ページには、Privateプロジェクトのページ内容を反映する。

- ページタイトル
- ページ本文
- ページ内のScrapboxリンク
- ページ内のハッシュタグ
- ページ内の画像・添付ファイルへの参照
- ページ履歴、作成者、更新者などのメタデータ

Privateプロジェクト内の複製対象ページへのリンクは、Publicプロジェクト内の対応するページへのリンクに変換する。

複製対象外のページへのリンクは、Publicプロジェクトのページから削除する。

画像および添付ファイル自体は複製せず、参照だけを変換する。

## 4. 個人情報の置換

Privateプロジェクト内の設定ページで管理する文字列置換設定に基づき、複製前にページタイトルとページ本文の文字列を置換する。

文字列置換設定は、置換対象文字列と置換後の文字列の組み合わせを複数指定できるものとする。

置換設定ページの本文には、1行につき1件の置換ルールを`置換前 => 置換後`の形式で記載する。

```text
山田太郎 => 公開用ユーザーA
東京都渋谷区 => 東京都内
個人メール@example.com => 非公開メール
成人向け表現 => 置換済み表現
```

空行および`=>`を含まない行は無視する。置換前または置換後が空の行は設定エラーとする。同じ置換前文字列を複数指定した場合は、後に記載された置換ルールを採用する。

## 5. 同期動作

複製対象ページに対応するページがPublicプロジェクトに存在しない場合、新規作成する。

対応するページが存在する場合、Privateプロジェクトの最新内容を反映して更新する。

Privateプロジェクトのページが削除された場合、または複製対象外となった場合、対応するPublicプロジェクトのページを削除する。

PublicプロジェクトからPrivateプロジェクトへの逆方向の同期は行わない。

置換後のページタイトルが重複する場合、Publicプロジェクトへの反映を行わずエラーとする。手動プレビューでは、重複する置換後タイトルを表示する。

## 6. 定期方法

ミラーリングは、`MIRROR_RUN_HOURS`で指定した時刻に定期実行する。実行時の分は00分に固定する。

`MIRROR_RUN_HOURS`は`時,時,時`形式で指定し、デフォルトは`8,16,24`とする。`24`は日付の切り替わり時刻を表す。

## 7. 手動実行

定期実行と同じミラーリング処理を手動で1回実行する場合は、`python -m tools.run_mirroring`を実行する。

`--preview`を指定すると、Publicプロジェクトへ書き込まず、ミラーリング対象ページ、除外ページ、置換ルール、置換後のページタイトルを標準出力へ表示する。

```text
python -m tools.run_mirroring
python -m tools.run_mirroring --preview
```
