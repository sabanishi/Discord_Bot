# 日記更新確認機能 現行仕様

[共通仕様へ戻る](アプリケーション仕様.md)

## 1. 概要

当日の日記ページが初期状態から変更されたか確認し、未更新の場合にDiscordで執筆を促す。

## 2. 実行タイミング

毎日、`CHECK_PAGE_TIME`に実行する。デフォルトは日本時間21:15である。

Botの起動時刻が当日の確認時刻以降だった場合、当日分を遅れて確認せず、翌日の実行時刻まで待機する。

## 3. 未更新の判定

対象日の日記の初期内容を生成し、Scrapbox APIから同名ページの全行を取得する。

初期内容と実ページを行単位で比較し、完全に一致する場合を「未更新」と判定する。ただし、末尾に追加された空行の数は比較から除外する。途中の空行、空白、本文の変更は更新として扱う。

## 4. Discord通知

未更新と判定した場合、`DISCORD_ALERT_CHANNEL_ID`で指定したチャンネルへ以下を送信する。

- `MENTION_TARGET`が設定されている場合は対象ユーザーへのメンション
- 日記更新を促すメッセージ
- 対象の日記ページURL

ページに何らかの変更がある場合は通知しない。
