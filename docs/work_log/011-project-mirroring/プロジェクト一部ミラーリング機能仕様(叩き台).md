# プロジェクト一部ミラーリング機能仕様（たたき台）

[共通仕様へ戻る](../../specifications/アプリケーション仕様.md)

## 1. 概要

非公開のScrapbox（Cosense）プロジェクトを原本とし、その一部のページを公開プロジェクトへ複製する。

公開プロジェクトへ複製するページは、原本プロジェクト内のページから公開可否を判定して選択する。原本のページが更新された場合は、公開プロジェクト側の複製ページにも更新内容を反映する。

## 2. 目的

原本プロジェクトに含まれる日記、研究メモ、個人情報、その他の公開に適さないページを公開プロジェクトへ複製せず、公開してよいページだけを共有する。

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| 原本プロジェクト | ページの正本を保持する非公開Scrapboxプロジェクト |
| 公開プロジェクト | 原本プロジェクトの一部を公開するためのScrapboxプロジェクト |
| 原本ページ | 原本プロジェクトに存在するページ |
| 複製ページ | 公開プロジェクトに作成された原本ページの複製 |
| ミラーリング | 原本ページの内容を複製ページへ反映する処理 |
| 除外タグ | ページを複製対象外とするためのタグ |

## 4. 対象プロジェクト

原本プロジェクトと公開プロジェクトをそれぞれ設定できるものとする。

- 原本プロジェクトは非公開プロジェクトを指定する。
- 公開プロジェクトは複製先の公開プロジェクトを指定する。
- 原本プロジェクトと公開プロジェクトは同一であってはならない。
- 原本プロジェクトのページを読み取り、公開プロジェクトのページを作成または更新する。

## 5. 複製対象ページの判定

### 5.1 基本条件

原本プロジェクト内のページを複製対象候補とし、除外条件に該当するページは複製しない。

ページ選択は除外方式とする。除外条件に該当しないページを複製対象とする。

### 5.2 除外タグ・除外アイコン

ページ本文に設定された除外タグまたは除外アイコンのいずれかを含むページは、複製対象外とする。

除外タグおよび除外アイコンは、原本プロジェクト内の設定ページで管理する。

初期設定は以下とする。

- `#diary`
- `#研究`
- [private.icon]

除外タグおよび除外アイコンは、設定ページの変更によって追加・変更できるものとする。

### 5.3 個人情報・NSFW情報の置換

個人情報やNSFW情報を含むページを内容判定によって除外するのではなく、原本プロジェクト内の設定ページで管理する文字列置換設定に基づいて自動的に置換する。

置換対象文字列と置換後の文字列の組み合わせを複数設定できるものとする。

## 6. 複製内容

複製ページには、原本ページの以下の情報を反映する。

- ページタイトル
- ページ本文
- ページ内のScrapboxリンク
- ページ内のハッシュタグ
- ページ内の画像・添付ファイルへの参照
- ページ履歴、作成者、更新者などのメタデータ

原本プロジェクト内の複製対象ページへのリンクは、公開プロジェクト内の対応する複製ページへのリンクに変換する。

複製対象外のページへのリンクは、公開プロジェクトのページから削除する。

画像および添付ファイル自体は複製せず、参照だけを変換する。

## 7. 個人名・識別情報の置換

複製前に、原本プロジェクト内の設定ページで設定された個人名その他の識別情報を、公開用の名称へ置換する。

- 置換対象文字列を複数設定できる。
- 置換後の文字列を対象ごとに設定できる。
- ページタイトルとページ本文の両方を置換対象とする。
- 置換は自動的に行い、公開前の手動確認は必須としない。

## 8. 同期動作

### 8.1 作成・更新

複製対象ページに対応する複製ページが公開プロジェクトに存在しない場合、新規作成する。

対応する複製ページが存在する場合、原本ページの最新内容を反映して更新する。

### 8.2 削除

原本プロジェクトから削除されたページ、または複製対象外となったページは、公開プロジェクトから削除する。

公開プロジェクト側で独自に作成されたページや編集された内容について、ミラーリング処理による動作は保証しない。

### 8.3 同期方向

原本プロジェクトから公開プロジェクトへの一方向同期とする。

公開プロジェクト側で行った編集を原本プロジェクトへ反映する双方向同期は対象外とする。

## 9. 実行方法

ミラーリングは、毎日8時、16時、24時に定期実行する。

手動実行は行わない。

公開前の確認は必須とせず、定期実行によって自動的に公開プロジェクトへ反映する。

1回の実行では、対象ページの判定、置換処理、複製ページの作成・更新・削除、結果の記録を行う。

## 10. エラー時の扱い

個別ページの処理に失敗した場合、他のページの処理を継続する。

処理に失敗したページについて、以下を記録する。

- ページタイトル
- 処理種別（作成・更新・削除など）
- 失敗理由

実行全体の結果として、成功件数、失敗件数、除外件数を確認できるものとする。

## 11. セキュリティ要件

- 原本プロジェクトの認証情報を公開プロジェクトへ公開してはならない。
- 個人情報やNSFW情報を含むページについて、設定された文字列置換が適用される前の内容を公開プロジェクトへ複製してはならない。
- ミラーリング処理のログに、認証情報を記録してはならない。
