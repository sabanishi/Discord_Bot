# プロジェクト一部ミラーリング機能 実装計画

> 状態: 2026-10-05に実装・ローカルモックテストを実施中。外部サービス確認は未実施

## 目的

`プロジェクト一部ミラーリング機能仕様.md`に定めた機能を、仕様を表すテストを先に作成しながら実装する。

この文書は、実装中に進捗と確認結果を記録するチェックリストとして使用する。

## 実装対象の仕様

- PrivateプロジェクトからPublicプロジェクトへの一方向ミラーリング
- 除外方式によるページ選択
- Privateプロジェクト内の設定ページによる除外タグ・除外アイコンの管理
- Privateプロジェクト内の設定ページによる文字列置換設定の管理
- ページタイトル・本文の文字列置換
- PrivateページへのリンクのPublicページ向け変換
- 複製対象外ページへのリンク削除
- ページ本文、画像・添付ファイルへの参照、ページメタデータの複製
- 原本ページの作成・更新・削除に対応したPublicページの作成・更新・削除
- Public側の編集内容を保証しない一方向同期
- 毎日8時、16時、24時の定期実行
- 手動実行なし
- 公開前確認なしの自動反映
- 個別ページの失敗後も継続するエラー処理
