# 既存テスト見直し結果

## テストの分類

### 設定・起動

- `tests/test_config.py`
  - 設定値の正常系、既定値、異常値、SID正規化、しきい値検証を確認している。
- `tests/test_main_startup.py`
  - `main()`と`__main__`ガードの構文を確認している。
- `tests/test_main_jobs.py`
  - `main()`の起動順序と日記ジョブの通知連携を確認している。

### 日記・通知・スケジューラ

- `tests/test_diary_service.py`
  - テンプレート、Cosense HTTP成功・異常系、作成後の再取得、セッション注入を確認している。
- `tests/test_notifications.py`
  - 通知成功、長文、チャンネル不存在、通常例外、Discord例外を確認している。
- `tests/test_scheduling.py`
  - 時刻計算、待機、日次ループ、間隔ループ、停止条件を確認している。

### Web・戦術対抗戦

- `tests/test_web_app_factory.py`
  - Flaskアプリ生成、UserScriptルート、API登録、サーバー起動・終了を確認している。
- `tactical_challenge/tests/test_http_api.py`
  - API成功、入力不正、環境変数不足、400・500エラー、CORSを確認している。
- `tactical_challenge/tests/`
  - 解析、クライアント、サービス、スケジューラの単体・結合テストを含む。

## 見直しで確認した不足

### 優先度高

- `main.py`をimportしたときに、実際の依存関係でWebサーバーやBotが起動しないことを確認できていない。
- `initialize_runtime()`の設定から各サービス生成までを一体で確認するテストが不足している。
- `on_ready()`で共有セッション、定期タスク、既存タスクの重複起動防止を確認していない。
- `on_disconnect()`で共有セッションとWebサーバーが終了することを確認していない。
- 日記・リンク警告・戦術対抗戦の各ループ本体と共通スケジューラの接続確認が不足している。

### 優先度中

- `main.py`から分割する関数の公開インターフェースがテストで固定されていない。
- 通知文の完全一致を確認する箇所と、主要部分だけを確認する箇所が混在している。
- `check_link_warnings.py`の引数解析と実行処理のテストが不足している。
- WebアプリのUserScriptレスポンス本文・Content-Typeの検証が一部不足している。

### 外部環境依存

- 外部ライブテスト7件はDNS障害のため未確認である。
- 実Discord依存関係を使った実プロセス起動は、現在のローカル環境では未確認である。

## 分割前に追加するテストの方針

- `main.py`の内部実装ではなく、分割後のモジュール境界をテストする。
- 起動処理は、初期化、タスク登録、Webサーバー起動、Bot起動、終了処理を分けて確認する。
- 各ジョブは、成功、無変更、失敗、重複起動防止を確認する。
- テストを先に追加し、未実装状態で失敗することを確認してから分割する。
