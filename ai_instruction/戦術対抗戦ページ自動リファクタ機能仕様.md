# 戦術対抗戦ページ自動リファクタ機能 仕様

[共通仕様へ戻る](アプリケーション仕様.md)

## 1. 概要

戦術対抗戦ページの編成欄に書かれた生徒名を検出し、Scrapboxのアイコン記法へ定期的に置換する。

```text
クロコ、エイミ、ホシノ、水イオリ
```

```text
[!クロコ.icon]・[!エイミ.icon]・[!ホシノ.icon]・[!イオリ(水着).icon]
```

## 2. 対象ページ

Scrapboxの`戦術対抗戦_シーズン一覧`ページに、処理対象を内部リンクとして列挙する。

```text
[対抗戦シーズン11_対戦相手]
[対抗戦シーズン12_対戦相手]
```

Botは設定ページからリンク先を取得し、各ページを処理する。対象ページをコードや環境変数へ直接列挙しない。

## 3. 編成行の検出

ページに専用マーカーを追加せず、本文から編成行を自動判定する。

### 3.1 主判定

1. 行を読点、カンマまたは中黒で分割する。
2. 各要素が生徒名か判定する。
3. 2名以上を認識し、かつ全要素の50%以上を生徒名と判定できた行を編成行とする。

インデントが崩れていても、複数の生徒名が列挙されていれば編成行として扱えるようにする。

行全体が単独の生徒名または略称と一致する場合は、無条件で編成行とする。

### 3.2 補助判定

主判定だけで確定できない場合は以下を利用する。

- 行のインデント
- 前後の行
- 対戦相手ブロック内での位置
- 周辺の編成行と同じインデントか

### 3.3 対象外

- ページタイトル
- 見出し
- 注釈や感想
- タグ
- URL
- すでにアイコン化されている記述

対戦相手名の末尾にある括弧内の生徒名は変換対象とし、ユーザー名部分は維持する。

```text
ナナこみ(水イオリ) → ナナこみ([!イオリ(水着).icon])
```

## 4. 生徒名の取得

Blue Archive攻略Wikiのキャラアイコン表から、通常衣装と別衣装を含む正式名称の一覧を取得する。

生徒ごとの略称辞書は手作業で管理しない。

## 5. 略称の生成

正式名称から一般的な略称を自動生成する。

```text
イオリ(水着) → 水着イオリ、水イオリ
ホシノ(臨戦) → 臨戦ホシノ
ミチル(ドレス) → ドレスミチル、ドミチル
ネル(制服) → 制服ネル
```

衣装名の短縮規則はScrapboxの`戦術対抗戦_略称`ページで管理し、新しい生徒にも同じ規則を適用する。

```text
水着
 水
正月
 正
ドレス
 ド
バニーガール
 バニー
 バニ
 バ
クロコ -> シロコ＊テラー
```

インデントのない行をWiki上の衣装名、その子行を短縮形として扱う。正式な衣装名を前置した別名は設定なしで生成する。

設定行全体に共通するインデントは無視し、衣装名と短縮形の相対的なインデントで親子関係を判定する。空行、各値の前後の余分な空白、タグ行は略称設定として扱わない。

衣装規則で表現できない別名は、`別名 -> 正式名称`形式で指定する。

同じ別名が複数の生徒を指す場合は設定エラーとし、曖昧な別名を使用しない。

## 6. 名前の照合

編成行を分割した各要素について、以下の順で照合する。

1. 正式名称との完全一致
2. 自動生成した略称との完全一致
3. 空白や表記記号を除去した正規化後の一致

一致しない要素は変更しない。部分一致や編集距離による自動置換は行わない。

文字列の類似度は、未認識名に対する候補の提示にのみ利用できる。

## 7. 置換

認識した名前を、対応する正式名称のアイコン記法へ置換する。

```text
水イオリ → [!イオリ(水着).icon]
```

置換処理は以下を満たすものとする。

- インデント、その他の文章を維持する。ただし、ページ内の`、`はすべて`・`へ置換する。
- すでにアイコン化された箇所を再変換しない。
- 同じページを複数回処理しても結果が変わらない。
- 変更がないページは更新しない。
- 未認識の名前は元の表記を維持する。

## 8. アイコンの生成

正式名称に対応するScrapboxアイコンページが存在しない場合、以下の手順で生成する。

1. 攻略Wikiから画像を取得する。
2. 画像をGyazoへアップロードする。
3. GyazoのURLを使ってScrapboxに`!正式名称`ページを作成する。

既存のアイコンページは再生成しない。

画像取得、Gyazoへのアップロード、アイコンページ作成の失敗によって、生成済みアイコンを使用した本文置換まで停止させない。

## 9. 自動生成ページ

ページ名は`!正式名称`とする。

```text
!イオリ(水着)
```

本文にはブラケットで囲んだGyazoの画像URL、自動生成を示す文、`#戦術対抗戦_アイコン`タグをこの順で記載する。自動生成を示す文の行頭には半角スペースを1文字付ける。

```text
!イオリ(水着)
[https://i.gyazo.com/0123456789abcdef.png]
 This page was auto generated.
#戦術対抗戦_アイコン
```

自動生成ページはBot専用Scrapboxアカウントで作成し、作成者をBotアカウントにする。

自動生成ページの作成日時を十分に古い日時へ変更し、ページ一覧の下部へ固定する。

## 10. 実行タイミング

毎日、`CHECK_PAGE_TIME`に実行する。デフォルトは日本時間21:15である。

Botの起動時刻が当日の実行時刻以降だった場合、当日分を遅れて実行せず、翌日の実行時刻まで待機する。

## 11. 更新と通知

変換前後に差分がある場合だけ対象ページを更新する。

処理が完了した場合、通常チャンネルへ特定の相手を想定しない簡潔な報告調で、対象ページ数、更新ページ数、変更行数、新規アイコン数を通知する。

以下の失敗はログへ出力し、特定の相手を想定しない簡潔な報告調でDiscordの警告チャンネルへ通知する。

- 設定ページまたは対象ページを取得できない
- Wikiから正式名称や画像を取得できない
- Gyazoへアップロードできない
- アイコンページを作成できない
- 対象ページを更新できない

未認識名は対象ページ単位でまとめて記録し、同じ内容を繰り返し通知しない。

## 12. UserScriptからの手動実行

ScrapboxのUserScriptから、表示中の対象ページだけを手動でリファクタできる。

- すべてのページでサイドバーに手動実行ボタンを表示する。
- ボタンを押した時点で、表示中のページが`戦術対抗戦_シーズン一覧`に登録された対象ページか確認する。
- 対象ページの場合だけ、表示中のページをリファクタする。
- 対象外のページではBotへ処理を依頼せず、対象外であることを画面に表示する。
- 実行中はボタンを無効化し、同じページへの重複実行を受け付けない。
- 完了時は、変更行数と新規アイコン数を画面上に表示する。
- 変更がない場合も、処理が完了したことを画面上に表示する。
- 失敗時は、ページを更新せず、エラー内容を画面上に表示する。

BotはUserScriptから受け取ったページ名が対象一覧に登録されている場合だけ処理し、対象外の場合は400として返す。正常時は処理対象ページ名、変更行数、新規アイコン数を返す。
