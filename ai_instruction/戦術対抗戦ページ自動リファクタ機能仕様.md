# 戦術対抗戦ページ自動リファクタ機能 仕様

[共通仕様へ戻る](アプリケーション仕様.md)

## 1. 概要

戦術対抗戦ページの編成欄に書かれた生徒名を検出し、Scrapboxのアイコン記法へ定期的に置換する。

```text
クロコ、エイミ、ホシノ、水イオリ
```

```text
[!クロコ.icon]、[!エイミ.icon]、[!ホシノ.icon]、[!イオリ(水着).icon]
```

## 2. 対象ページ

Scrapboxの`戦術対抗戦_シーズン一覧`ページに、処理対象を内部リンクとして列挙する。

```text
[対抗戦シーズン11_対戦相手]
[対抗戦シーズン12_対戦相手]
```

Botは設定ページからリンク先を取得し、各ページを処理する。対象ページをコードや環境変数へ直接列挙しない。

## 3. 編成行の検出

ページに専用マーカーを追加せず、本文から編成行を自動判定する。

### 3.1 主判定

1. 行を読点またはカンマで分割する。
2. 各要素が生徒名か判定する。
3. 2名以上を認識し、かつ全要素の50%以上を生徒名と判定できた行を編成行とする。

インデントが崩れていても、複数の生徒名が列挙されていれば編成行として扱えるようにする。

行全体が単独の生徒名または略称と一致する場合は、無条件で編成行とする。

### 3.2 補助判定

主判定だけで確定できない場合は以下を利用する。

- 行のインデント
- 前後の行
- 対戦相手ブロック内での位置
- 周辺の編成行と同じインデントか

### 3.3 対象外

- ページタイトル
- 見出し
- 対戦相手のユーザー名
- 注釈や感想
- タグ
- URL
- すでにアイコン化されている記述

## 4. 生徒名の取得

Blue Archive攻略Wikiのキャラアイコン表から、通常衣装と別衣装を含む正式名称の一覧を取得する。

生徒ごとの略称辞書は手作業で管理しない。

## 5. 略称の生成

正式名称から一般的な略称を自動生成する。

```text
イオリ(水着) → 水着イオリ、水イオリ
ホシノ(臨戦) → 臨戦ホシノ
ミチル(ドレス) → ドレスミチル、ドミチル
ネル(制服) → 制服ネル
```

衣装名の短縮規則はScrapboxの`戦術対抗戦_略称`ページで管理し、新しい生徒にも同じ規則を適用する。

```text
水着 → 水
正月 → 正
ドレス → ドレス、ド
制服 → 制服
臨戦 → 臨戦
```

## 6. 名前の照合

編成行を分割した各要素について、以下の順で照合する。

1. 正式名称との完全一致
2. 自動生成した略称との完全一致
3. 空白や表記記号を除去した正規化後の一致

一致しない要素は変更しない。部分一致や編集距離による自動置換は行わない。

文字列の類似度は、未認識名に対する候補の提示にのみ利用できる。

## 7. 置換

認識した名前を、対応する正式名称のアイコン記法へ置換する。

```text
水イオリ → [!イオリ(水着).icon]
```

置換処理は以下を満たすものとする。

- 区切り文字、インデント、その他の文章を維持する。
- すでにアイコン化された箇所を再変換しない。
- 同じページを複数回処理しても結果が変わらない。
- 変更がないページは更新しない。
- 未認識の名前は元の表記を維持する。

## 8. アイコンの生成

正式名称に対応するScrapboxアイコンページが存在しない場合、以下の手順で生成する。

1. 攻略Wikiから画像を取得する。
2. 画像をGyazoへアップロードする。
3. GyazoのURLを使ってScrapboxに`正式名称.icon`ページを作成する。

既存のアイコンページは再生成しない。

画像取得、Gyazoへのアップロード、アイコンページ作成の失敗によって、生成済みアイコンを使用した本文置換まで停止させない。

## 9. 自動生成ページ

ページ名は`正式名称.icon`とする。

```text
イオリ(水着).icon
```

本文にはGyazoの画像URLを記載する。

自動生成ページはBot専用Scrapboxアカウントで作成し、作成者をBotアカウントにする。

自動生成ページの作成日時を十分に古い日時へ変更し、ページ一覧の下部へ固定する。

## 10. 実行時刻

毎日、日本時間21:15に実行する。

## 11. 更新と通知

変換前後に差分がある場合だけ対象ページを更新する。

以下の失敗はログへ出力し、Discordの警告チャンネルへ通知する。

- 設定ページまたは対象ページを取得できない
- Wikiから正式名称や画像を取得できない
- Gyazoへアップロードできない
- アイコンページを作成できない
- 対象ページを更新できない

未認識名は対象ページ単位でまとめて記録し、同じ内容を繰り返し通知しない。
