現在のCosense公式仕様で動画埋め込み対象になっているのは、**Gyazo GIF、YouTube、Vimeo**です。ニコニコ動画は含まれていません。([scrapbox.io](https://scrapbox.io/help-jp/%E5%8B%95%E7%94%BB%E3%82%92%E5%9F%8B%E3%82%81%E8%BE%BC%E3%82%80?utm_source=chatgpt.com))

さらに、過去に実際にUserScriptからニコニコのiframeを挿入する実験が行われていますが、CosenseのContent Security Policy（CSP）の `frame-src` によって `embed.nicovideo.jp` が拒否されています。当時のエラーは、許可対象が `www.youtube.com` や `player.vimeo.com` などに限定されている、というものでした。([scrapbox.io](https://scrapbox.io/villagepump/Scrapbox%E3%81%AB%E3%81%84%E3%82%8D%E3%82%93%E3%81%AA%E3%82%82%E3%81%AE%E3%82%92%E5%9F%8B%E3%82%81%E8%BE%BC%E3%82%80?utm_source=chatgpt.com))

つまり整理すると、

| 方法 | ニコニコ埋め込み |
|---|---|
| `[ニコニコURL]` を普通に書く | ❌ 現在非対応 |
| UserScriptでiframeを生成 | ❌ CSPに阻まれる |
| ProjectScriptでiframeを生成 | 基本的に同じCSP制約を受ける |
| Cosense本体が正式対応 | **✅ 可能** |
| Cosense側で `frame-src https://embed.nicovideo.jp` を許可 | **✅ 原理上可能** |
| CSPを変更可能な独自/オンプレ環境 | **✅ 原理上可能** |

したがって結論は、

> **Scrapboxの構造上、ニコニコ動画をYouTubeと同様に埋め込むこと自体は十分可能。しかし、現在のクラウド版Cosenseでは「ニコニコ動画用のパーサがない」ことに加えて「CSPがiframeを阻止する」ため、通常のUserScriptだけで完全な埋め込みを追加するのは難しい。**

という状態です。

```text id="qjry4f"

│
├─ Chrome拡張の iframe
│   chrome-extension://xxxxx/player.html
│
│   └─ ニコニコ動画の iframe

│
└─ Scrapbox本文
```

```html id="uob75d"

```

を作らないことです。


さらに、制限の強いCSPを持つページに対して、

```text id="2vrwtb"

  ↓
chrome-extension://.../frame.html
  ↓
https://外部サイト
```

というラッパーiframeを使う手法は、Chrome拡張で実際に使われている回避方法です。([stackoverflow.com](https://stackoverflow.com/questions/24641592/injecting-iframe-into-page-with-restrictive-content-security-policy?utm_source=chatgpt.com))


`manifest.json`

```json id="jc8vwq"

  "name": "Cosense Niconico Embed",
  "version": "0.1.0",

  "content_scripts": [

        "https://scrapbox.io/*"

      ]
    }
  ],

  "web_accessible_resources": [
    {
      "resources": [
        "player.html",
        "player.js"
      ],
      "matches": [
        "https://scrapbox.io/*"
      ]
    }
  ],

  "content_security_policy": {
    "extension_pages":
      "script-src 'self'; object-src 'self'; frame-src https://embed.nicovideo.jp;"
  }
```

`player.html`

```html id="vjl1ic"
      height: 100%;
```

```js id="g8sxch"

const id = params.get("id");

if (/^[A-Za-z0-9_-]+$/.test(id)) {
  document.getElementById("player").src =
    `https://embed.nicovideo.jp/watch/${encodeURIComponent(id)}`;
}
```

```js id="c2esk1"
const url = "https://www.nicovideo.jp/watch/sm9";

  new URL(url).pathname.match(/^\/watch\/([^/]+)/)?.[1];

const player = document.createElement("iframe");

player.src =

player.style.width = "640px";
player.style.height = "360px";

```

となります。

特に試す価値があるのが、通常の

```js id="so3z89"

});
```

で追加して回避した実例もあります。([stackoverflow.com](https://stackoverflow.com/questions/69786354/tampermonkey-script-blocked-by-a-csp-error?utm_source=chatgpt.com))

```js id="wupkfd"
// ==/UserScript==

(() => {

    GM_addElement(document.body, "iframe", {
        src: "https://embed.nicovideo.jp/watch/sm9",
        style: `
            width: 640px;
            height: 360px;
            position: fixed;
            right: 20px;
            bottom: 20px;
            z-index: 999999;
            border: none;
        `,

        allowfullscreen: "true"

})();
```


```js id="d0jjwr"
// ==UserScript==
// @name         Cosense Niconico Embed
// @namespace    https://scrapbox.io/
// @version      1.0.0
// @description  Cosense上のニコニコ動画リンクをインラインプレイヤーとして埋め込む
// @match        https://scrapbox.io/*
// @grant        GM_addElement
// ==/UserScript==

(() => {
    "use strict";

    const EMBED_CLASS = "tm-niconico-embed";

    /**
     * ニコニコ動画URLから動画IDを取得する
     */
    function getVideoId(urlString) {
        try {
            const url = new URL(urlString, location.href);

            // https://www.nicovideo.jp/watch/sm9
            if (
                url.hostname === "www.nicovideo.jp" ||
                url.hostname === "nicovideo.jp"
            ) {
                const match = url.pathname.match(/^\/watch\/([^/?#]+)/);
                return match?.[1] ?? null;
            }

            // https://nico.ms/sm9
            if (url.hostname === "nico.ms") {
                const match = url.pathname.match(/^\/([^/?#]+)/);
                return match?.[1] ?? null;
            }

            return null;
        } catch {
            return null;
        }
    }

    /**
     * 指定されたリンクの近くにプレイヤーを追加する
     */
    function embedPlayer(anchor) {
        if (!(anchor instanceof HTMLAnchorElement)) {
            return;
        }

        const videoId = getVideoId(anchor.href);

        if (!videoId) {
            return;
        }

        // このリンクはすでに処理済み
        if (anchor.dataset.niconicoEmbedded === "true") {
            return;
        }

        anchor.dataset.niconicoEmbedded = "true";

        /*
         * Cosenseではリンクが行内に存在するため、
         * その行の直後にプレイヤーを置く。
         */
        const line = anchor.closest(".line") ?? anchor.parentElement;

        if (!line) {
            return;
        }

        const wrapper = document.createElement("div");
        wrapper.className = EMBED_CLASS;

        Object.assign(wrapper.style, {
            width: "640px",
            maxWidth: "100%",
            aspectRatio: "16 / 9",
            margin: "8px 0 12px 0",
        });

        line.insertAdjacentElement("afterend", wrapper);

        GM_addElement(wrapper, "iframe", {
            src: `https://embed.nicovideo.jp/watch/${encodeURIComponent(videoId)}`,

            style: `
                display: block;
                width: 100%;
                height: 100%;
                border: 0;
                background: #000;
            `,

            allow: "autoplay; fullscreen; picture-in-picture",
            allowfullscreen: "true",
            loading: "lazy",
        });
    }

    /**
     * DOMの中からニコニコ動画リンクを探す
     */
    function scan(root) {
        if (!(root instanceof Element || root instanceof Document)) {
            return;
        }

        if (root instanceof HTMLAnchorElement) {
            embedPlayer(root);
        }

        root.querySelectorAll?.("a[href]").forEach(embedPlayer);
    }

    /*
     * 初回表示
     */
    scan(document);

    /*
     * CosenseはSPAなので、
     * ページ遷移や編集によって追加されたDOMも監視する。
     */
    const observer = new MutationObserver((mutations) => {
        for (const mutation of mutations) {
            for (const node of mutation.addedNodes) {
                if (node instanceof Element) {
                    scan(node);
                }
            }
        }
    });

    observer.observe(document.body, {
        childList: true,
        subtree: true,
    });
})();
```

```text id="v3irip"

  ↓

  ↓
embed.nicovideo.jp
```

方式です。これが一番きれいです。CosenseのService WorkerやCSPを書き換える必要がないので、リロード方法にも依存しません。


ただしCosenseが起動時に再登録する可能性があるので、そこも実際の挙動を確認してからコード化した方がいいです。

ただし、これは今のTampermonkey方式と同じく「CosenseのCSPを書き換える」系統なので、Service Workerとの相互作用は実機検証が必要です。Safariはページに拡張が追加した要素にもページCSPを適用する挙動が報告されているため、単純にextension iframeを挟むだけでは十分でない可能性があります。([developer.apple.com](https://developer.apple.com/go/?ext=true&id=wwdc26-web-extensions-q-and-a&utm_source=chatgpt.com))

そして、もう一つかなり面白い方法があります。

「ニコニコ公式プレイヤーでなくても、Cosense内で動画を視聴できればよい」のであれば、CSPを一切変更しない方法が作れます。

現在のCosenseのCSPは、

```text id="1ub84w"
frame-src ...
```

については厳しい一方、

```text id="tom4vr"
media-src *
```

になっています。2026年の実際のCosenseレスポンスでも確認できます。([urlscan.io](https://urlscan.io/result/019bd548-f52d-7647-8735-f2d0cbff6355?utm_source=chatgpt.com))

つまり、

```html id="ftuo27"
<iframe src="https://embed.nicovideo.jp/...">
```

はダメですが、

```html id="m6rxfi"
<video src="https://...">
```

による動画読み込みは任意ドメインから許可されています。

そこで、

```text id="qptmva"
Cosense標準UserScript
        ↓
[https://www.nicovideo.jp/watch/sm9]
を検出
        ↓
自分のサーバー
https://example.com/nico/sm9.mp4
        ↓
<video controls src="...">
```

という構成にできます。

サーバー側でニコニコの動画ストリームを取得し、ブラウザで再生可能なMP4/fMP4として中継します。

```text id="pxqr99"
             ┌─────────────────┐
             │     Cosense     │
             │                 │
ニコニコURL →│   UserScript    │
             │       ↓         │
             │    <video>      │
             └───────┬─────────┘
                     │
             media-src * なので通る
                     │
                     ▼
             自分の動画Proxy
                     │
                     ▼
              ニコニコ配信基盤
```

現在のニコニコは `delivery.domand.nicovideo.jp` から署名付きHLSを配信していることが確認できます。([github.com](https://github.com/yt-dlp/yt-dlp/issues/12376?utm_source=chatgpt.com)) したがって、サーバー側でストリームを解決してブラウザ向けにremuxすること自体は技術的に可能です。

この方式にはかなり大きな利点があります。

| 方法 | Mac | iPhone | iPad | 端末側追加ソフト |
|---|---:|---:|---:|---|
| Tampermonkey | ○ | ×/不安定 | ×/不安定 | 必要 |
| Safari Web Extension | ○ | ○ | ○ | 必要 |
| HelpfeelにCSP追加してもらう | ○ | ○ | ○ | 不要 |
| `<video>` + 自前Proxy | ○ | ○ | ○ | 不要 |

最後の方式なら、端末側には何もインストールしません。

Cosenseのプロフィールに一度、

```text id="ro9z9z"
code:script.js
```

を書くだけです。Mac・iPhone・iPadで同じCosenseアカウントを使えば、同じUserScriptが実行されます。

ただし欠点も明確です。

```text id="3ry90z"
公式iframe方式
→ ニコニコ公式プレイヤー
→ コメント等もそのまま利用可能

video + Proxy方式
→ 自作videoプレイヤー
→ 動画視聴は可能
→ ニコニコ公式UI・コメントは別途実装が必要
→ 自分のサーバーが動画帯域を負担
```

なので、目的別にはこう考えます。

> 「ニコニコ公式プレイヤーをCosense内にそのまま出したい」
>
> → HelpfeelにCSP対応してもらうのが最良。自力ならMac/iOS/iPadOS共通Safari Web Extension。

> 「とにかくMac・iPhone・iPad全部でCosense内から動画を再生したい」
>
> → **Cosense標準UserScript + `<video>` + 自前の動画Proxy** が、端末依存をなくせる最も興味深い方法です。

今回の要件なら、私は後者を一度PoCします。`media-src *` というCosense側の既存仕様を使うので、これまで苦しんでいた `frame-src` とService Worker問題を丸ごと避けられます。
